# City Dynamics Explorer

An interactive web simulator of the *Simple City Dynamics* model: move policy sliders and see
how jobs, housing, transportation, migration and the city budget respond over 50 years.

**Try it: https://hazhirr.github.io/city-dynamics-explorer/**

This repository only hosts the compiled website (branch `gh-pages`), which is published
automatically from a private repository. The model and the source code are not public.

Model: *Simple City Dynamics* by Hazhir Rahmandad (MIT Sloan School of Management). Built with
[SDEverywhere](https://github.com/climateinteractive/SDEverywhere).
